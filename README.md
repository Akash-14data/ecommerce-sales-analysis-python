# ecommerce-sales-analysis-python
E‑commerce Sales Data Analysis using Python, Pandas, NumPy, and Plotly. Focused on data cleaning, KPI tracking, trend analysis, and interactive visualizations to uncover insights on revenue, customer behavior, and product performance.
## Tools Used
- Python
- Pandas
- NumPy
- Plotly
## Project Overview
This project analyzes ecommerce sales data, performs data cleaning, and creates interactive visualizations to identify business insights and trends.
## Files Included
- Jupyter Notebook (.ipynb)
- Dataset files
- Project visualizations
